Before you let it run overnight

prove a check can fail before you trust it passing

Nine checks for anyone running an AI agent unattended.

I run AI agents on my own servers, unsupervised, on real work. In the space of a few days they truncated a file I had no backup of, staged a secret into git twice, quoted stale status as live, died silently mid-job, and acted on a proposal as if it were an order. Every one of those was caught. None was caught by the agent.

This is the runbook I wish I'd had: nine checks, each with the failure that made me write it, each with a test you can plant to prove the check works. No security theory. Ops, from the operator's chair.

  • What counts as an instruction (and what doesn't)
  • Acknowledge before acting
  • Silence is the alarm
  • Every check names what it examined
  • Plant the positive before you trust the negative
  • "It turned out fine" is not a safeguard
  • Seal what's sealed before you edit anything
  • A run that produced nothing must not exit clean
  • The second pair of eyes that owes the first one nothing
